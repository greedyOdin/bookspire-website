Code einlösen

Hast du einen Code für Bookspire bekommen, etwa von einer Creatorin oder einem Creator? Gib hier die E-Mail-Adresse deines Bookspire-Kontos und den Code ein. Wenn du die App das nächste Mal öffnest, wartet dein Geschenk in deinem Lesezimmer auf dich.

Neu bei Bookspire?

Lade dir die App kostenlos für iPhone oder Android. Du kannst deinen Code schon vorher hier einlösen: Meldest du dich in der App mit derselben E-Mail-Adresse an, wartet dein Geschenk bereits auf dich.

Du brauchst die neueste Version der App. Wofür wir deine Adresse speichern, steht in der Datenschutzerklärung.
